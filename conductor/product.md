# Product Definition

## Project Name

options-analyzer

## Description

A professional-grade options trading analysis platform with real-time Greeks, market indicators, and a Bloomberg-style web interface.

## Problem Statement

Retail options traders need institutional-quality analytics (second-order Greeks, trend signals, regime detection) without paying for Bloomberg Terminal.

## Target Users

Active options traders managing complex positions (butterflies, spreads, condors) who need real-time Greeks and market condition monitoring.

## Key Goals

1. **Complete Greeks Analysis** — Provide first and second-order Greeks with real-time streaming from TastyTrade
2. **Bloomberg-Quality Visualization** — Deliver professional-grade visualization in a modular, tiling web interface with dark theme
3. **Provider-Agnostic Architecture** — Support hexagonal architecture with ports and adapters for future broker integrations
