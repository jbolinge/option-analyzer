## Summary

Set up the monorepo structure with a FastAPI backend API layer and a Vite + React + TypeScript frontend, establishing end-to-end connectivity from browser to Python engine.

## Context

The options-analyzer currently uses Jupyter notebooks as its only interface. This track creates the foundational infrastructure for a Bloomberg-style web frontend: a FastAPI backend that exposes existing engine functionality via REST endpoints, and a React SPA that will consume those endpoints.

## User Story

As an options trader, I want a web-based interface foundation so that future views (market dashboard, positions, option chain) can be built on a solid, tested architecture.
